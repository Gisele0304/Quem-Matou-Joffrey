Estruturas de dados

Diferentes estruturas foram utilizadas para organizar, armazenar e manipular as informações da investigação.

Lista sequencial

Armazena elementos em sequência, permitindo inserção, busca e remoção.

Lista encadeada

Organiza elementos por meio de nós conectados.

Pilha

Utiliza a lógica LIFO: o último elemento inserido é o primeiro a sair.

Fila

Utiliza a lógica FIFO: o primeiro elemento inserido é o primeiro a sair.

Deque

Permite inserir e remover elementos no início e no final.

Tabela Hash

Utiliza uma função de dispersão para localizar elementos por suas chaves.

Aplicação na investigação

As estruturas de dados permitem organizar os registros, controlar o histórico de acontecimentos e facilitar a localização das evidências relacionadas ao caso.
